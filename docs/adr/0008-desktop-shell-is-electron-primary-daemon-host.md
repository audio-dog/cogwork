# Desktop shell is Electron; it is the primary daemon host

Mission control ships as an Electron app (electron-vite + electron-builder), not Tauri and not browser-tab-first. The desktop app is the primary **daemon** host on a laptop: it supervises a bundled Node child that boots the server layer, stays single-instance, and on window-close hides to the tray/dock while the engine keeps running. The CLI remains a thin **client** and a headless host for CI/SSH. We rejected `ELECTRON_RUN_AS_NODE` and `utilityProcess` so the RunAsNode fuse can stay off in a paid-product hardening story; first-party Rust/native modules are not needed for tray, socket RPC, or credentials (`safeStorage` later). Forge was rejected in favor of the coding-agent reference path (opencode/t3code) and `electron-updater` over GitHub releases.
